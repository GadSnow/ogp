| Endpoint / objet                                     | Changement                                                                                                                                                                           | Action côté front                                                                                                                     |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **POST `/facture/add`**                              | `idCampagne` devient optionnel. Sans lui, `idRegie` devient obligatoire et un nouveau paramètre `montantBrute` doit être fourni (montant saisi à la main, aucun panneau à calculer). | Nouveau parcours « facture de redevance » : formulaire avec choix de la régie et saisie manuelle du montant, sans campagne ni remise. |
| **Objet Facture (toutes les réponses)**              | `typeFacture` peut désormais valoir `"redevance"`, en plus de `"campagne"` et `"autorisation"`                                                                                       | Adapter l’affichage/filtre qui teste déjà `typeFacture`                                                                               |
| **POST `/paiement/add`**                             | Nouveau paramètre `justificatif` (fichier). Obligatoire si `modePaiement` vaut **Cheque** ou **Virement**, sinon erreur 400                                                          | Pour ces deux modes, envoyer la requête en `multipart/form-data` avec le fichier ; pour Cash, rien ne change                          |
| **Modes de paiement disponibles**                    | Deux nouveaux modes créés : **Cheque** et **Virement** (en plus de Cash)                                                                                                             | Les proposer dans le sélecteur de mode de paiement, avec le champ justificatif qui apparaît pour ces deux-là uniquement               |
| **Objet Paiement (toutes les réponses)**             | Deux nouveaux champs : `justificatifNomFichier` (nom du fichier, à afficher) et `justificatifTypeMime`. Un troisième champ interne (`justificatifChemin`) n'est jamais renvoyé       | Afficher le nom du fichier joint quand il existe (`justificatifNomFichier != null`)                                                   |
| **Nouveau GET `/paiement/justificatif?idPaiement=`** | Télécharge le justificatif. Réponse en fichier brut (pas de JSON Result), avec le bon type et le nom d'origine                                                                       | Lien de téléchargement/visualisation direct depuis cette URL                                                                          |
| **PUT `/paiement/update`**                           | La restriction « Cash uniquement » s'étend à Chèque et Virement : ces trois modes redeviennent modifiables, tout mode Soutra reste bloqué                                            | Aucun changement de contrat, juste plus de paiements modifiables qu'avant                                                             |
